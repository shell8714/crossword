# ことばクロスワード

ひらがなで解く 7×7 の日本語クロスワード（試作版）です。ブラウザだけで動きます。

- 全14問。ヒント、答え合わせ、答え表示つき
- 「ゃ ゅ ょ っ」は大きい「や ゆ よ つ」で入力します
- 盤面はプログラムで自動生成し、カギは手作業で書いています

## 遊び方

GitHub Pages の公開URLを開くか、`index.html` をブラウザで開いてください。
